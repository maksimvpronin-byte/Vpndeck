# Что нового

## 0.1.7 — не выпущена

Приложение:
- Проверка туннеля больше не опирается на адрес, который по HTTPS не отвечал никогда
  (msftconnecttest.com); третий адрес — detectportal.firefox.com.
- Сторож соединения и обновление профиля больше не могут тихо остановиться, если два запроса
  к серверу совпали по времени.
- Переход на отдельный UUID устройства — в фоне через несколько секунд после подключения,
  а не во время него: подключение не ждёт перезапуска Xray на сервере.
- Отключённое на сервере устройство видит «Это устройство отключено на сервере», а не
  «Неверный логин или пароль». Экран входа показывает, почему закончилась прошлая сессия.
- На одном телефоне можно войти в другой аккаунт: для него заводится отдельное устройство.
- Самообновление не зависает на «Установка…», если во время загрузки уйти из приложения:
  карточка предлагает «Установить», уведомление возвращает в приложение. Найденная версия
  не пропадает из карточки после перезапуска приложения.
- Сессия не копируется на новый телефон при переносе данных Android.
- Плитка в шторке позволяет отменить зависшее подключение.

Сервер:
- Общий UUID для старых версий приложения больше не может оказаться UUID чьего-то телефона
  (если общего клиента удалили или передвинули в конфиге Xray).
- `devices restore <id>` возвращает отозванное устройство с новым UUID; отозванные не входят
  в лимит 100; `devices` показывает дату регистрации.
- Причина отказа устройству передаётся приложению (`device_revoked`, `device_other_account`).
- Конфиг Xray при изменении устройств сохраняет порядок и оформление ключей.
- Таймауты перезапуска Xray и ответа API согласованы (25 с и 60 с).
- Необязательный срок жизни старых токенов: `legacy_token_max_age_days`.
- Go 1.26; unit-файл с запасом памяти под `docker restart`; свои настройки — в drop-in.
- `setup-xray.sh` ставит закреплённую версию Xray (26.10.21), а не `latest`.

## 0.1.6

- Отдельный UUID и токен на каждую установку приложения: `vpndeck-server devices`,
  `devices enable <контейнер>`, `devices revoke <id>`. Существующие сессии переходят
  на свой UUID без повторного ввода пароля; серверы без этой функции поддерживаются.
- Отключение отменяет незавершённое подключение. При недоступности API используется
  сохранённый профиль; ответ 401 завершает сессию, а изменившийся ключ останавливает VPN.
- Главный экран различает проверку, рабочий туннель и восстановление соединения;
  проверки используют несколько независимых адресов.
- «Диагностика → Проверить соединение» с копируемым отчётом (без пароля, токена, UUID и адреса).
- CI запускает серверные тесты с race detector, go vet, Android unit-тесты и lint до сборки APK.
